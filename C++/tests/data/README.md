# Regression fixtures

`all-special-resolution-v9.hic` is an independent 214-byte synthetic Juicer-style
fixture. Its ordinary chromosome resolutions are 1,000,000 and 100,000, while
its All matrix stores one count=7 contact at a separate 6,176-unit resolution.
This covers the resolution mismatch that otherwise produced a blank All view.

`trans-v10.hic` is the small synthetic trans fixture from Straw's
`R/inst/extdata/trans-v10.hic`, generated by `C++/tests/test_v10.py:fixture`.
It has chrA (80 bp, index 0), chrB (70 bp, index 1), and asymmetric trans
contacts at 10 bp resolution. It intentionally has no stored All chromosome.
CARTON uses it to verify chromosome enumeration and requested-axis orientation.

`all-last-v10.hic` is Straw's synthetic `C++/tests/pseudo-all.hic` fixture.
Its table order is chrA (95 bp), chrB (75 bp), All (18 stored units).
It was generated with hictools-c native pre and add-all repair from HBS
cells chrA:14/chrA:25, chrA:14/chrB:6, and chrB:0/chrB:74.
Tests also make a temporary same-length `ALL` header variant to cover casing.
